# v0.31.0 — A service name given once and never written down

Release date: 2026-09-29

Bump level: **MINOR**. The rendered `.copier-answers.yml` gains a line, and
an interactive `copier copy` asks one more question, with a default. That is
backward-compatible scaffold output: not a PATCH (`docs/RELEASING.md` §1.1),
and no §1.3 contract changes. `MIGRATION.md` has no entry, because no manual
action is needed beyond answering the new question.

## Why this release exists

`service_name` was a `when: false` question, like the derived casings, so it
was never written to `.copier-answers.yml`. A downstream repository generated
its service with `--data service_name="Demand Forecast Serving"`, and that
value existed only on its command line. A regeneration from the answers file
alone differed from the committed service in 60 files. Any `copier update`
without the same flag would re-render each changed line as
`DemandForecastServing`, one release at a time.

`service_name` is now an ordinary question with the same PascalCase default
(#254). `--defaults` renders exactly what it did, and the value is recorded
whether it is the default or not. It reaches only display text: docstrings,
the API title, log lines, workflow and artifact labels. `service_kebab` and
`service_upper` reach identifiers, so they stay derived. ADR-030 §2.3 carries
the amendment, and `scripts/test_scaffold.sh` asserts the answer is recorded.

Also in this release:

- Dependabot updates in the service: `uvicorn ~= 0.54.0` (#248, and #246 in
  `examples/minimal`), `boto3 ~= 1.43.103` (#250), and `setuptools >= 84.0.0`
  as the build requirement (#233).
- Dependabot stops proposing ydata-profiling 4.13+, which caps matplotlib
  below the pinned 3.11 (#245).

## Adopter impact

- The next `copier update` asks for `service_name` once, offering the
  PascalCase default. If you had overridden it, pass
  `--data service_name="…"` so the override is recorded; with `--defaults`,
  the default is recorded instead.
- `requirements.txt` moves uvicorn to 0.54.

## Known follow-ons

- **L4 remains unproven.** No cloud deployment is claimed.
- **The numpy 1.x boundary is still unmeasured**, and it blocks the `shap` and
  `pandas` majors.
- **Two service skill names are generic enough to collide with an adopter's
  own** (`doc-coherence`, `enterprise-audit`). Reported downstream; a rename
  is a template decision not yet taken.
